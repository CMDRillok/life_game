## идея
Когда клетка умирает, она оставляет в почве накопленную органику и энергию.
Клетки объединяются в организм, которым управляет семя. Задача организма сохранить жизнь и адаптироваться к новым условиям (повышенное содержание органики, энергии или нехватка места)
При создании нового организма (отсоединении семени) слегка изменяется генетический код (случайно меняются параметры)
### типы клеток
#### зелёная 
Собирает энергию из воздуха, то есть поглощает свет.
#### оранжевая
Собирает органику из почвы и преобразовывает в энергию. действует в области 3x3
#### синяя
- собирает энергию из почвы.
- каждая клетка при смерти теряет свою накопленную энергию
#### серая
- Это стебель. Служит для перемещения энергии от одной клетки к другой
- так же является буфером. количество хранимой энергии ограничено
#### белая
- Семя. Хранит генетический код и служит центром принятия решений. 
- при создании второй белой клетки в одном организме она может либо отстрельнуть и создать новый организм либо развиваться в пределах старого организма.
- Если семя отстрельнулось, то при попадании в другую клетку семя унечтожит эту клетку и потратит энергию.
- за один тик генерации семя отдаёт один приказ создания клеток либо может сдвинуться на одну клетку и на предыдущем месте появится стебель
- создание любой клетки тратит энергию накопленную в семени

## реализация
- для каждой клетки свой класс
- класс для всего организма
### код 
- в самом начале создаётся матрица для поля `desk = np.zeros((10, 10), dtype=int)`
- class Desk: класс для поля и методы для него 
	- get: возвращает поле в виде матрицы
	- print_desk: выводит доску, как матрицу
- инициализация классов
