## идея
Когда клетка умирает, она оставляет в почве накопленную органику и энергию.
Клетки объединяются в организм, которым управляет семя. Задача организма сохранить жизнь и адаптироваться к новым условиям (повышенное содержание органики, энергии или нехватка места)
При создании нового организма (отсоединении семени) слегка изменяется генетический код (случайно меняются параметры)
### типы клеток
#### зелёная 
Собирает энергию из воздуха, то есть поглощает свет.
#### оранжевая
Собирает органику из почвы и преобразовывает в энергию. действует в области 3x3
#### синяя
- собирает энергию из почвы.
- каждая клетка при смерти теряет свою накопленную энергию
#### серая
- Это стебель. Служит для перемещения энергии от одной клетки к другой
- так же является буфером. количество хранимой энергии ограничено
#### белая
- Семя. Хранит генетический код и служит центром принятия решений. 
- при создании второй белой клетки в одном организме она может либо отстрельнуть и создать новый организм либо развиваться в пределах старого организма.
- Если семя отстрельнулось, то при попадании в другую клетку семя унечтожит эту клетку и потратит энергию.
- за один тик генерации семя отдаёт один приказ создания клеток либо может сдвинуться на одну клетку и на предыдущем месте появится стебель
- создание любой клетки тратит энергию накопленную в семени

## текущая реализация (этап 4b)

Поле 2000×2000 с зацикливанием, панорамой, зумом и четырьмя слоями просмотра.
Слои хранятся как массивы numpy (SoA), без объектов на клетку.

Порядок тика:

1. BFS `dist_seed` от семени по стеблям — только при изменении топологии;
2. производство энергии (зелёные/оранжевые/синие);
3. инъекция энергии работников в соседние стебли;
4. переток по стеблям к семени (не больше одной клетки за тик);
5. голодная смерть оранжевых/синих и разложение в органику;
6. одно действие семени: создать клетку или сдвинуться.

### рост организма

- **Стебли создаются только ходом семени.** Семя сдвигается на 1 клетку по
  4 направлениям, а на прежнем месте остаётся стебель. Прямого приказа
  «создать стебель» у семени нет.
- Ход стоит 5 энергии семени (это оплата оставленного стебля); энергия
  переезжает в новое семя.
- Работник создаётся в любой свободной клетке, соседней со **стеблем своего
  организма** по 4 направлениям, а не обязательно рядом с семенем. Стоимость
  работника — 20 энергии семени.
- Работники (зелёная/оранжевая/синяя) не могут соседствовать друг с другом,
  включая диагонали (запрет по 8 направлениям). Проверка выполняется при
  создании.
- За тик семя делает ровно одно действие: ход или создание работника.
- Default-политика: организм стремится иметь ~2 стебля на работника + 3.
  Пока стеблей меньше нормы, семя двигается и тянет стебель; иначе создаёт
  работника. Тип работника детерминированно чередуется зелёный → оранжевый →
  синий. Если выбранное действие невозможно, семя пробует второе.
- Цели для работников перебираются от дальних концов BFS к ближним, поэтому
  новые клетки появляются по краям организма.
- Список работников поддерживается инкрементально: новый работник добавляется
  при создании, умершие вычищаются сразу после смерти; полная пересборка —
  только после resize/load/ручной смены топологии.

### запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python main.py
```

По умолчанию включается демо-сцена: шум в слоях органики/энергии и небольшой
организм в центре. Пустое поле — `--empty`.

Headless-прогон:

```bash
.venv/bin/python main.py --headless --ticks 500 --save checkpoints/run.npz
```

### управление

- `1` / `2` / `3` / `4` / `Tab` — клетки / органика почвы / энергия почвы /
  энергия клеток;
- `Space` — пауза, `N` — один тик, `PageUp`/`PageDown` — скорость симуляции;
- ЛКМ/ПКМ-драг, WASD или стрелки — панорама;
- колесо мыши — зум к курсору;
- `[` / `]` — ширина поля, `-` / `=` — высота;
- `G` — сетка, `R` — сброс камеры, `F` — вписать поле, `Esc` — выход;
- `--sim-hz` — целевая скорость симуляции (по умолчанию 30 тиков/с);
- `--save path.npz` — сохранить поле при выходе, `--load path.npz` — загрузить.

HUD показывает тик, измеренную скорость, энергию семени, суммарную энергию
клеток и количество живых клеток по типам. Рост и движение семени идут в том
же тике, поэтому пауза и `N` останавливают и их.

### бенчмарк

```bash
.venv/bin/python benchmark.py
```

Показывает аллокацию, скорость полных проходов по памяти, стоимость `np.roll`
(который в горячем тике использовать нельзя), время пересборки BFS, стоимость
тика симуляции и время сборки кадра.
